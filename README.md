Проект «Фитнес-клуб»

Описание проекта

Проект «Фитнес-клуб» предназначен для хранения информации о клиентах, тренерах, абонементах, услугах и посещениях. С системой могут работать администраторы и сотрудники фитнес-клуба. База данных позволяет отслеживать сроки действия абонементов, платежи клиентов и записи на групповые занятия. Руководитель может анализировать количество посещений, популярность услуг и активность клиентов. Таблица visits хранит историю посещений и рассчитана на накопление большого количества записей. Для поиска информации предусмотрено текстовое поле с описанием цели посещения. Проект создан с использованием PostgreSQL и SQL.

Основные таблицы

* clients — клиенты клуба.
* trainers — тренеры.
* memberships — справочник абонементов.
* subscriptions — оформленные абонементы.
* services — справочник услуг.
* equipment — спортивное оборудование.
* visits — история посещений.
* group_classes — групповые занятия.
* class_enrollments — записи клиентов на занятия.
* specializations — справочник специализаций.
* trainer_specializations — связи тренеров со специализациями.
* payments — платежи клиентов.

Технологии

* PostgreSQL
* SQL
